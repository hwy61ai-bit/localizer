Per-event opener overlay + render-staleness detection + per-row / bulk re-render actions. Spec at `docs/SPEC_OPENER_RERENDER.md` (ratified by Tim July 8). Whole feature landed in one afternoon end-to-end; gated at ship time only on two `ALTER TABLE events ...` migrations run manually in Supabase.
